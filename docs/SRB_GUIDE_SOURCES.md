## Подключение

Добавлен **[@rabotavbelgrade1](https://t.me/rabotavbelgrade1)** — публичный канал
«Работа в Белграде / Сербия». Ссылка находится в описании чата
[@rabotavbelgrade](https://stats.srb.guide/channels/rabotavbelgrade).
Это связанный канал, а не доступ к сообщениям самого чата.

На проверенной последней странице 20 постов, 13 прошли распознавание вакансии
с подтверждённой локацией в Сербии. Это результат разбора страницы, а не обещание
13 новых уникальных вакансий: копии других источников объединяет общий каталог.
Канал использует обычный ограниченный обход с checkpoint, повторным чтением
свежих постов и историей до 90 дней. Стало 24 активных источника, из них 7 Telegram.
Пользователь не выбирает источники; новые кнопки в его меню не добавляются.

Публичная страница `t.me/s/...` возвращает страницу сообщества без сообщений.
Статус не означает отсутствия вакансий: участник может читать чат в Telegram,
но текущий анонимный сборщик не получает его историю. Вход под пользовательским
аккаунтом, вступление в чаты и изменение настроек бота не выполнялись.
Для отдельного приёма новых сообщений из группы потребуется разрешение её
администрации и отдельная реализация; обычный Bot API не отдаёт прошлую историю.

Проверка обнаружила два ложных совпадения в @srbijabiz: подборку нескольких
должностей и интервью с упоминанием прошлого найма. Их исключение покрыто
регрессионными тестами Telegram-сборщика. Интервью и подборки не импортируются
как одна вакансия. Отдельные объявления с обычным описанием собеседования сохраняются.
