# Управление с телефона

Рабочий @SerbiaJobsBot уже перенесён в **Telegram Serverless**. Render должен
оставаться приостановленным. Supabase содержит историческую копию миграции;
не выполняйте старые инструкции Render Deploy, установку webhook Python-бота
или старого расписания Check Serbia jobs.

Для текущего обслуживания откройте GitHub → AngryVirus/serbia-jobs-bot → Actions:

- **Test bot** — результаты проверок `tests` и `security`.
- **Serbia Jobs Serverless** — публикация, сбор и фоновые операции. После
  успешных проверок объединённого main публикация запускается автоматически.
  Ручная операция `check` проверяет активность и маршрутизацию; `deploy`
  публикует проверенный текущий код. Публикация сама по себе не подтверждает
  доставку вакансий: смотрите результат сбора и диагностику владельца.
- **Independent bot watchdog** — независимые проверки здоровья.
- **Encrypted SQLite backup** — зашифрованные копии и проверка восстановления.

Функции команды и рекламы доступны в `/admin` в Telegram в пределах текущей
роли. Обычным пользователям административные кнопки не показываются.

Подробности и актуальные команды:
[README](README.md), [серверная архитектура](serverless/README.md),
[эксплуатация/восстановление](serverless/OPERATIONS.md), [защита](SECURITY.md).
Не меняйте и не перевыпускайте секреты для обычного обновления. Их значения
вводятся только в защищённые настройки сервисов, не в чат и не в поля workflow.

Архивные `render.yaml`, `deploy/serbia-jobs-bot.service` и
`deploy/legacy-collect.yml.disabled` сохранены для истории. Python polling/webhook
заблокирован по умолчанию; обход защиты предназначен только для изолированного
legacy-тестового бота. Старый ZIP удалён: актуальный исходный архив собирается
из проверенного коммита командой, указанной в README.
